# Meus Links - Projeto de Perfil Pessoal

Um site responsivo que centraliza os principais links e redes sociais em um único lugar, com suporte a tema claro e escuro.

## Funcionalidades

- Perfil pessoal com foto e username
- Alternância entre tema claro e escuro
- Links diretos para LinkedIn, GitHub e Portfólio
- Ícones de redes sociais (GitHub, WhatsApp, LinkedIn)
- Design responsivo e mobile-first
- Interface moderna com gradientes e efeitos visuais

## Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização com variáveis CSS e tema dinâmico
- **JavaScript** - Lógica de alternância de temas
- **Figma** - Criação de interfaces
- **Ionicons** - Ícones das redes sociais
- **Google Fonts** - Fonte Inter
